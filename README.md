## 👋 About

I build production **React Native** apps and the **design-system tooling** behind them. At **Lendistry** I work across a mobile lending app, its web counterparts, and the shared UI kits that keep iOS, Android and web visually and behaviourally consistent.

- 📱 Shipping a multi-tenant, server-driven mobile lending experience (apply flow, hub, entry/sign-in) for iOS & Android
- 🧩 Building and maintaining shared component libraries and design tokens used across mobile and web
- 🔁 Keeping mobile in **web parity** with the React web apps: business rules as tested, pure functions
- 🌍 Internationalisation, accessibility and Android/iOS platform-parity work

## 🔭 How I work

- **Parity over guesswork**: I check the web implementation before porting a behaviour to mobile.
- **Rules as pure, tested functions** (visibility, validation, calculations) rather than logic buried in JSX.
- **Design tokens, not magic values**: colours, radii and shadows come from one source of truth.
- **Small PRs, one branch per ticket**, with the Jira key in every commit.
